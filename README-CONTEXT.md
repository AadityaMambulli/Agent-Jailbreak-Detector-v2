# Context System: Quick Start

**For:** Razorpay Buildathon (Agentic Payment Jailbreak Detector)

---

## Three Context Files

| File | Purpose | Update When |
|------|---------|------------|
| **PROJECT_CONTEXT.md** | Problem + timeline + tech stack (stable) | Rarely (scope change) |
| **CURRENT_STATE.md** | Progress tracker (what's done, blocked) | Every session |
| **DECISIONS.md** | Why you chose what (avoid re-debate) | Hit new obstacles |

---

## How to Use (3 Steps)

### Step 1: New Chat Session
Paste all 3 files. Tell LLM:
```
"Read these context files. Help me with: [your task]"
```

### Step 2: Work
Build stuff. LLM has full context.

### Step 3: Before Closing
Ask LLM:
```
"Update CURRENT_STATE.md and DECISIONS.md, then show me"
```
Copy updated files → commit to GitHub.
